Problem 33: Digit Cancelling Fractions

The fraction 49/98 is a curious fraction, as an inexperienced mathematician incorrectly cancelling the 9s would get 49/98 = 4/8, which is correct. Fractions like 30/50 = 3/5 are trivial examples. There are exactly four non-trivial examples less than one in value with two digits in numerator and denominator. If the product of these four fractions is given in its lowest common terms, find the value of the denominator.
